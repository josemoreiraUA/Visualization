Modern web browsers prevent web applications from accessing files stored on a user's computer without explicit permission. Therefore, the datasets required for the examples provided by this platform must be loaded into the application before they can be processed. All data remains on the user's machine and data processing is performed entirely within the browser using DuckDB-WASM, eliminating the need for a backend server or database installation.

The modules in the top navigation bar depend on specific input datasets and each module remains disabled until all of its required files have been loaded. Once loaded, the datasets can be previewed and queried using the integrated DuckDB SQL workspace.
